# Timmy Digital

Static marketing site for Timmy Digital. Built with HTML, CSS, and a small JavaScript file for the mobile menu and footer year.

## Preview locally

From this folder, run:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before publishing

- Confirm the service descriptions, geographic focus, and positioning.
- Add a domain, then set the canonical URL, social preview metadata, and a sitemap.
- Replace or supplement the Gmail enquiry address if a branded address becomes available.
- Add genuine case studies or client proof when available. This draft contains no invented results.
- Deploy the static files to a private S3 bucket behind CloudFront, with an Origin Access Control. Set a billing budget before creating infrastructure.

The site uses [Impeccable](https://github.com/pbakaus/impeccable) design guidance. The Bricolage Grotesque and DM Sans font licenses are in `assets/fonts/`.
